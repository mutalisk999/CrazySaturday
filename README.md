# 疯狂星期六抢1大赛 🎱

一个基于 Python Tkinter 的桌球比赛模拟系统，支持选手管理、比赛进程跟踪、连胜统计等功能。

## 功能特性 ✨

### 核心功能
- **选手管理**：支持添加、编辑、删除选手，设置初始 HP（2-8 条命）
- **固定参赛选手**：管理常用选手信息（姓名、联系方式、邮箱、住址）
- **比赛模拟**：自动分配选手到球台，支持 1-20 张球台，可自定义桌号顺序
- **比赛名称**：支持为每场比赛设置名称，便于区分和记录
- **HP 跟踪**：实时显示选手剩余命数，红色标记仅剩 1 条命的选手
- **连胜统计**：实时统计并显示全场最长连胜数
- **比赛记录**：记录每场比赛的胜负详情
- **逆天改命**：支持手动修改选手的生命值
- **选手弃赛**：支持赛中选手、球桌候补、场外候补弃赛，HP直接扣为0
- **挑战者加入**：比赛中途可新增挑战者，自动加入场外候补区

### 界面特性
- 🎨 现代化 UI 设计，卡片式布局
- 📊 Treeview 表格展示选手信息
- 🔄 实时更新比赛状态
- 💾 支持保存/加载比赛状态
- ⏪ 支持状态回退和前进
- 📐 球台固定尺寸，每行最多3张，布局美观

## 快速开始 🚀

### 运行程序
```bash
python crazy_saturday.py
```

### 基本使用流程

1. **选手设置**
   - 添加参赛选手（姓名 + 初始 HP）
   - 或使用"固定参赛选手"功能快速导入

2. **开始比赛**
   - 点击"重新开始比赛"
   - 输入比赛名称（必填）
   - 选择球桌数量（1-20张）
   - 可自定义桌号顺序（如：2,5,6,8,10）

3. **比赛进行**
   - 点击"判负"按钮记录比赛结果
   - 系统自动处理人员轮转
   - 实时显示连胜统计和比赛记录

4. **撤台操作**
   - 点击球台上的"撤台"按钮标记该球台
   - 当前对局结束后该球台关闭
   - 选手移至场外候补区

5. **特殊操作**
   - **逆天改命**：修改选手生命值
   - **选手弃赛**：让选手退出比赛，HP扣为0，移至淘汰区
   - **挑战者加入**：比赛中途新增选手，加入场外候补区

6. **数据管理**
   - 可随时保存/加载比赛状态
   - 支持状态回退和前进

## 比赛规则 📜

### 球台使用顺序
默认球台使用顺序为：2→3→4→5→6→7→8→9→1

支持自定义桌号顺序，例如：2,5,6,8,10（适合特殊场地布局）

| 初始球台数 | 默认使用球台编号 |
|-----------|-----------------|
| 1张       | 2号             |
| 2张       | 2-3号           |
| 3张       | 2-4号           |
| 4张       | 2-5号           |
| 5张       | 2-6号           |
| 6张       | 2-7号           |
| 7张       | 2-8号           |
| 8张       | 2-9号           |
| 9张       | 2-9号、1号      |

### 撤台规则
- 撤台由用户手动触发，点击球台上的"撤台"按钮
- 点击后该球台标记为"即将撤桌"状态（红色标题栏）
- 当前对局结束后，该球台关闭
- 球台上的选手移至场外候补区

### 比赛流程
1. 擂主 vs 挑战者，1局定胜负
2. 败方：移至场外候补区队尾，HP-1
3. 胜方：留在擂主位置
4. 候补区选手依次补位
5. HP=0 时移至淘汰区

### 特殊功能
- **逆天改命**：可修改未淘汰选手的生命值，用于纠正误操作或特殊情况处理
- **选手弃赛**：
  - 赛中选手（擂主/挑战者）弃赛：HP直接扣为0，移至淘汰区，对方获胜，球台位置自动调整
  - 球桌候补选手弃赛：HP直接扣为0，移至淘汰区，场外候补区第一个选手自动补位
  - 场外候补选手弃赛：HP直接扣为0，移至淘汰区
- **挑战者加入**：比赛中途可新增挑战者，设置姓名和HP（2-8），自动加入场外候补区尾部
